# À lire avant de téléverser sur GitHub

La version actuellement en ligne apparaît sans design parce que les fichiers de style/images n'ont probablement pas été publiés correctement, notamment le dossier `assets/`.

## Solution

1. Ouvrir le ZIP.
2. Entrer dans le dossier `projetnova_site_premium_github`.
3. Sélectionner **tout le contenu** à l'intérieur du dossier : fichiers HTML + dossiers `assets` et `documents`.
4. Téléverser le tout dans GitHub à la racine du dépôt.
5. Vérifier que GitHub affiche bien :
   - `index.html`
   - `assets/`
   - `documents/`
   - `CNAME`

Si `assets/` n'apparaît pas dans GitHub, le design ne pourra pas afficher les images.
