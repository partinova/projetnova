# À lire avant l’envoi sur GitHub

1. Décompressez le ZIP.
2. Envoyez tout le contenu du dossier décompressé dans le dépôt GitHub, pas le ZIP.
3. Assurez-vous que `index.html`, `assets/`, `documents/` et `CNAME` apparaissent à la racine du dépôt.
4. Message de commit recommandé : `Refonte finale professionnelle du site Projet Nova`.
5. Attendez quelques minutes avant de tester le site.
