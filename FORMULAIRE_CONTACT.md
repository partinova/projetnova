# Formulaire de contact — Projet Nova

Le site utilise maintenant Formspree pour l’envoi automatique des formulaires.

Endpoint utilisé :

```text
https://formspree.io/f/xkolwjdg
```

Pages branchées :

- `contact.html`
- `participer.html`

Le même endpoint est utilisé pour les deux formulaires. Le champ caché `Formulaire` permet de distinguer :

- `Contact Projet Nova`
- `Participation Projet Nova`

## À vérifier dans Formspree

1. Le formulaire `Contact Projet Nova` doit être actif.
2. L’adresse de réception doit être `officiellenovaparti@gmail.com`.
3. Faire un test depuis `https://www.partinova.ca/contact.html`.
4. Faire un test depuis `https://www.partinova.ca/participer.html`.
5. Vérifier les messages dans l’onglet `Submissions` de Formspree.
6. Activer l’authentification à deux facteurs sur le compte Formspree.
