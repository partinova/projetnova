# Formulaire de contact Projet Nova

Les pages `contact.html` et `participer.html` utilisent FormSubmit :

```html
<form action="https://formsubmit.co/officiellenovaparti@gmail.com" method="POST">
```

## Activation obligatoire

Au premier message envoyé depuis le site, FormSubmit envoie un courriel de confirmation à :

officiellenovaparti@gmail.com

Il faut ouvrir ce courriel et cliquer sur le bouton de confirmation. Après cela, les prochains messages seront livrés automatiquement.

## Tests

1. Publier les fichiers sur GitHub.
2. Ouvrir https://www.partinova.ca/contact.html
3. Envoyer un message test.
4. Vérifier la boîte Gmail officielle et les spams.
5. Confirmer FormSubmit si demandé.

## Boutons de secours

Les pages incluent aussi :
- un bouton Gmail ;
- un bouton application courriel ;
- un bouton pour copier le courriel officiel.
