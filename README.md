# Projet Nova — site public

Site officiel du Projet Nova.

Version publique actuelle : V1.6 officielle intégrée.

## Documents publiés

Le site publie seulement les PDF officiels V1.6 : manifeste, programme, Livre Nova, FAQ, Constitution, lois organiques, lois administratives, lois ordinaires, règlements, registre des risques, rapport d’intégration, rapport de comparaison / intégration et index général.

## Règles de publication

Aucun DOCX, ZIP, 7Z, RAR, archive de travail ou fichier de modification interne ne doit être publié sur le site.

Les addendum séparés ne sont pas utilisés. Les éléments utiles doivent être intégrés directement aux documents officiels avant publication.

Domaine : www.partinova.ca
