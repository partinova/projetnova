Propositions citoyennes

Dire ce qui devrait changer.

Les citoyens peuvent signaler publiquement une situation, proposer une amélioration ou indiquer ce qui devrait être corrigé. Les messages sont transmis au Projet Nova et peuvent être publiés après validation.

Registre public

Un espace pour écouter, classer et corriger.

Cette page sert à recevoir des propositions citoyennes sur les services publics, les lois, les institutions, la transparence, l’administration, la vie quotidienne ou toute situation que les citoyens jugent importante.

Publication après validation : pour protéger les citoyens, éviter les abus et respecter la vie privée, les messages ne sont pas publiés automatiquement. Le Projet Nova les reçoit par courriel, les vérifie, puis peut les publier dans le registre public.

« Une démocratie sérieuse doit entendre les problèmes réels avant de proposer des solutions. »

Cadre de publication

Ce qui sera accepté.

Les propositions doivent être utiles, compréhensibles et orientées vers une solution.

  • Problème observé ou amélioration proposée.
  • Catégorie publique : santé, éducation, administration, transparence, économie, région, etc.
  • Publication possible après validation.
  • Possibilité d’ajouter un statut : reçu, en analyse, à corriger, corrigé ou archivé.
Important : les messages privés, les plaintes sensibles ou les accusations personnelles doivent être envoyés par le formulaire Contact, pas publiés dans ce registre.
Messages publics validés

Registre citoyen.

Les contributions approuvées seront affichées ici avec leur statut de suivi. Le registre est modéré pour protéger la qualité du débat public.

Comment publier une proposition approuvée : après validation, ajoutez-la au fichier data/propositions-publiques.json, puis téléversez le site sur GitHub. Cela garde le registre public propre, vérifiable et modéré.
